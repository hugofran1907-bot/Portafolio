
## 🚀 Subir a GitHub y Vercel

### Opción 1: Con GitHub Desktop (la más fácil)

1. Descarga GitHub Desktop: https://desktop.github.com
2. Abre GitHub Desktop
3. "File" → "New Repository"
4. Nombre: `portfolio-hugo`
5. Carpeta: elige dónde guardaste los archivos
6. "Create Repository"
7. "Publish repository"

### Opción 2: Con Terminal

```bash
git init
git add .
git commit -m "Portfolio inicial"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/portfolio-hugo.git
git push -u origin main
```

### Conectar a Vercel

1. Entra a https://vercel.com/dashboard
2. Click en "Add New Project"
3. Conecta tu repositorio de GitHub
4. Vercel despliega automáticamente
5. Tendrás tu link: `https://portfolio-hugo.vercel.app/`
